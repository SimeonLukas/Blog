Ich zeig euch heute mal, wie ich aus einem Kindle aus der vergangenen Zeit meinen Hub für das Smart Home gemacht habe. Das Ganze ist eigentlich ein Tutorial für meinen lieben Freund J und für alle anderen, die vielleicht auch so ein altes Kindle Gerät herumliegen haben und es als Smart Home Dashboard nutzen möchten, oder einfach nur, weil sie Spaß an so etwas haben. Zweitausendzwanzig hat mir mein Schwager das alte Kindle vier Touch geschenkt, das er nicht mehr brauchte. Ursprünglich wollte ich es ganz normal als E Book Reader nutzen, aber nach ein paar Wochen merkte ich, dass ich es kaum benutzte. Also begann ich, nach anderen Verwendungsmöglichkeiten zu suchen.

Mein Konzept war im Grunde ein Interface, das jeden Endzeitkrieg übersteht. Das Kindle soll ein bisschen wie so ein Pip Boy sein, naja, zumindest ein kleines bisschen. Es soll mir ermöglichen, mein Smart Home und die Squeezeboxen zu steuern, ohne dass ich ständig mein Smartphone oder den PC benutzen muss. Das Gerät ist robust und braucht wenig Strom. Außerdem hat es einen E Ink Bildschirm, der auch bei direkter Sonneneinstrahlung gut lesbar ist, was perfekt für den Einsatz in verschiedenen Lichtverhältnissen ist. Zudem dient es als Anzeige für unterschiedliche Bilder, je nach Wetter, und auch die Abfallabfuhrtermine sollen erkennbar sein. Also fast wie ein Pip Boy, nur eben ohne die Waffen und den Rest. Das einzige, was vielleicht ein bisschen daran erinnert, ist die Tatsache, dass das Gerät die Musik steuert und einfach alt ist.

Technisch gesehen basiert das Projekt auf mehreren Technologien und Komponenten. Bei der Software nutze ich HTML für die Struktur, CSS für das Design und die richtige Anzeige auf dem E Ink Display, JavaScript für die Interaktivität und PHP für die serverseitige Logik. Bei der Hardware verwende ich einen jailbroken Kindle vier Touch als Display und Steuergerät, ein Micro USB Kabel für die Stromversorgung und ich habe das Ganze in einen Bilderrahmen als Gehäuse gepackt.

Jetzt zum Thema Jailbreak. In diesem Jahr sind tatsächlich die alten Developer Zertifikate für das Mobileread Kindlet Kit abgelaufen. Dadurch funktionieren die Extensions, vor allem KUAL, also der Kindle Unified Application Launcher, auf den früheren jailbroken Kindle Geräten nicht mehr. Aber keine Sorge, es gibt eine Lösung. Mit den neuen Zertifikaten von NiLuJe läuft alles wieder wie geschmiert. Ich erklär euch kurz, wie ihr euer Kindle vier Touch jailbreaken könnt. Zuerst verbindet ihr dein Kindle mit dem Computer und sichert alle wichtigen Daten. Dann ladet ihr die neuesten Updates für euer Kindle herunter. In diesem Fall, beim Kindle vier Touch, muss das Gerät bis zur Version fünf Punkt drei Punkt sieben Punkt drei aktualisiert werden. Die Datei im bin Format kopiert ihr in das Wurzelverzeichnis des Kindles und installiert sie über das Menü in den Einstellungen unter Kindle aktualisieren. Das Gerät startet danach neu. Als Nächstes ladet ihr die Jailbreak Dateien herunter, entpackt sie und kopiert den Inhalt der entsprechenden Zip Datei ebenfalls in das Wurzelverzeichnis eures Kindles. Danach tauscht ihr die Zertifikate aus. Ihr ladet die neuen Zertifikate von NiLuJe herunter und ersetzt die alte Datei namens developer keystore im Wurzelverzeichnis. Zum Schluss installiert ihr den Jailbreak, indem ihr ihn über das Menü in den Einstellungen bei Kindle aktualisieren aktiviert. Wenn alles geklappt hat, müsste am unteren Rand des Bildschirms das Wort Jailbreak stehen. Das Gerät muss danach neu gestartet werden.

Falls euer Kindle bereits jailbroken ist, könnt ihr direkt die Zertifikate austauschen. Dazu ladet ihr die passende bin Datei von NiLuJe herunter, in meinem Fall war das die Datei Update mkk zweitausendzwanzigfünf null vier eins neun k vier ALL keystore install Punkt bin, und packt sie in das Wurzelverzeichnis eures Kindles. Danach installiert ihr die Datei wieder über das Menü in den Einstellungen unter Kindle aktualisieren. Dann sollte KUAL wieder funktionieren.

Jetzt geht es an die Installation von KUAL und WebLaunch. Für KUAL ladet ihr die neueste Version herunter, entpackt die Zip Datei und kopiert die Datei KUAL KDK zwei Punkt null Punkt azw zwei in das Documents Verzeichnis eures Kindles. Danach macht ihr das gleiche mit WebLaunch. Ihr ladet die neueste Version herunter, entpackt sie und kopiert den gesamten Inhalt in ein Verzeichnis namens WebLaunch im Extension Verzeichnis eures Kindles. Damit das Ganze läuft, müsst ihr noch eine Konfigurationsdatei namens settings Punkt js im WebLaunch Verzeichnis erstellen und anpassen. Die Struktur ist so, dass die Datei settings Punkt js zusammen mit den anderen WebLaunch Dateien im Extension Ordner liegt, während die KUAL Datei im Documents Ordner liegt. In dieser settings Datei legt ihr im Grunde fest, welche IP Adresse euer Dashboard hat, wobei es per HTTP erreichbar sein muss, oder ihr gebt eine lokale HTML Datei an, die dann im bin Ordner liegen muss. Außerdem könnt ihr dort den Titel festlegen, zum Beispiel Pip Boy Home, die Statusleiste ausblenden, das WLAN aktivieren, die Power Taste zum Schließen nutzen und einstellen, ob das Display im Querformat angezeigt werden soll. Wenn ihr KUAL auf dem Homescreen startet und WebLaunch auswählt, sollte die Webseite erscheinen.

Jetzt seid ihr an der Reihe. Nachdem ihr euer Kindle erfolgreich jailbroken und KUAL sowie WebLaunch installiert habt, könnt ihr euer eigenes Smart Home Dashboard erstellen. Ich hab da ein kleines Beispiel vorbereitet, wie ihr eine HTML Seite für euer Dashboard gestalten könnt. Ihr erstellt im Grunde eine einfache Webseite mit einer Überschrift und einem Button, um zum Beispiel das Licht an oder aus zu schalten. Im Hintergrund läuft ein kleines JavaScript. Ich nutze hier eine Funktion, die eine Anfrage an die API eures Smart Home Systems sendet, in meinem Beispiel an eine Shelly API über eine bestimmte IP Adresse, um den Zustand des Lichts zu ändern. Wichtig ist hierbei, dass das JavaScript auf dem Kindle nur eingeschränkt unterstützt wird, also aktuelle Funktionen wie fetch fehlen dort leider.

Damit das Ergebnis optisch gut aussieht, habe ich noch ein wenig CSS hinzugefügt. Damit werden die Bilder in einem Container auf eine Breite von zweihundert Pixeln gesetzt und die großen Bilder nehmen fast die gesamte Breite von fünfundneunzig Prozent ein, damit alles sauber auf dem Display verteilt ist.

Mein Fazit ist, dass aus einem verstaubten E Reader von zweitausendelf ein funktionales Smart Home Dashboard geworden ist, und das mit überraschend wenig Aufwand. Das Kindle überzeugt durch seinen stromsparenden E Ink Bildschirm, die einfache Bedienung und die robuste Hardware. Was als Experiment begann, läuft nun seit Monaten zuverlässig und steuert täglich Licht, Musik und andere Smart Home Geräte. Alte Hardware muss nicht im Schrank verstauben, manchmal braucht sie einfach nur eine neue Aufgabe. Und falls doch mal die Apokalypse kommt, haben wir schon mal ein funktionierendes Terminal. Das war's für heute, viel Spaß beim Ausprobieren.
