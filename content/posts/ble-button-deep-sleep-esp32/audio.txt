# 🛠️ Project: ESP32 BLE Low-Power Button

This project creates a wireless button that wakes up from deep sleep, connects via Bluetooth as a HID (Human Interface Device) keyboard, sends a keystroke, and returns to sleep to save battery.

## 🛒 Hardware Requirements
*   **Microcontroller:** ESP32 (e.g., ESP32-C3, ESP32-S3)
*   **Button:** Momentary Push Button
*   **Power:** LiPo Battery or similar DC power source
*   **Optional:** Resistor (if not using internal pull-ups)

## ⚙️ How it Works (Technical Breakdown)

### 1. Power Management (Deep Sleep)
The core of this project is the use of **Deep Sleep**. Instead of running the Bluetooth radio constantly (which would drain a battery in hours), the ESP32 is put into a low-power state. It only wakes up when the button triggers a hardware interrupt.

### 2. The Logic Flow
1.  **Wake Up:** The button press triggers a wake-up event.
2.  **Initialization:** The ESP32 starts the Bluetooth HID stack.
3.  **Keystroke:** The device identifies itself as a keyboard and sends the character `'2'` (as defined in the code).
4.  **Timeout:** To prevent immediate sleep (which might cause "bounce" or missed connections), the code waits for a short period or checks the connection.
5.  **Deep Sleep:** The device calls `esp_deep_sleep_start()`, turning off the CPU and Radio.

### 3. Key Code Components
*   **`NimBLE` Library:** The code uses the NimBLE library (a more memory-efficient version of the standard BLE library) to handle the HID keyboard profile.
*   **HID Descriptor:** It tells the receiving device (Phone/PC) "I am a keyboard."
*   **Wake-up Source:** Configured via `esp_sleep_enable_ext0_wakeup()` or `ext1`, depending on the specific GPIO pin used for the button.

## 🚀 Quick Setup Guide

1.  **Install Libraries:** Install the `NimBLE-Arduino` library via the Arduino Library Manager.
2.  **Upload Code:** Flash the provided sketch to your ESP32.
3.  **Pairing:** 
    *   Press the button to wake the device.
    *   Open Bluetooth settings on your Phone/PC.
    *   Pair with the device (usually named "ESP32 Keyboard" or similar).
4.  **Testing:** Open a text editor and press the button; you should see the number `2` appear.

## 📝 Notes for Customization
*   **Change the Key:** To change what the button "types," look for the `hidKeyboard.sendKey()` or similar function and replace the key code.
*   **Adjust Sleep:** You can modify the `delay()` before sleep to keep the device awake longer for multiple presses.
*   **Battery Life:** For maximum longevity, ensure you are using a development board with a low-quiescent-current voltage regulator.
